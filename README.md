# zhyldtaryh

7-класс үчүн кыргыз тилиндеги эки багыттуу тарых курсу. Кыргызстандын тарыхы жана дүйнө тарыхы боюнча ар бир багытта 5 лекция, 2 практикалык иш, 6 тест жана зачётко даярдануу бөлүмү бар.

Курс Кыргыз билим берүү академиясынын 2026-жылдагы, 6-класстан 7-класска өткөн окуучулар үчүн болжолдуу календардык-тематикалык планындагы тандалган темаларга негизделет. Расмий документке шилтеме жана темалардын байланышы «КТП» бөлүмүндө берилген.

Архивди ачып, жергиликтүү нусканы көрүү үчүн index.html файлын браузерден ачыңыз. GitHub Pages үчүн ушул файлдар main бутагынын түпкү папкасында жайгашат.

Прогресс ушул браузерде сакталат. Практикалык иштерди текст файлы катары жүктөп алууга болот.
